# BlazorDbzPersonagem

Aplicação Blazor em C# que consulta a Dragon Ball API pelo ID do personagem e exibe nome, planeta de origem e transformações.

## Requisitos
- .NET 8 SDK
- Visual Studio 2022 com a carga de trabalho ASP.NET e desenvolvimento Web, ou terminal com o .NET SDK

## Executar
1. Extraia o ZIP.
2. Abra `BlazorDbzPersonagem.csproj` no Visual Studio.
3. Execute com F5.

Alternativamente, abra um terminal nesta pasta e execute:

```bash
dotnet run
```

A aplicação usa o endpoint `https://dragonball-api.com/api/characters/{id}`. É necessária conexão com a internet.

## GitHub
Crie um repositório chamado `blazor-dbz-api-personagem` e envie os arquivos do projeto. Não é necessário enviar pastas geradas como `bin` e `obj`.
